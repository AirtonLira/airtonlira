## 👋 Sobre mim

Engenheiro de IA e arquiteto de dados, com mais de 13 anos de estrada. Comecei como assistente administrativo, fui estagiário mexendo com Clipper e ADVPL, virei DBA SQL Server e passei por engenharia de dados e ciência de dados até chegar em IA.

Hoje eu desenho e construo **plataformas de dados** e **sistemas de agentes de IA** para fintechs: do pipeline no Databricks/AWS até o agente em produção, com avaliação, observabilidade e custo sob controle. Escrevo e falo sobre isso para a comunidade (**+10 mil seguidores no LinkedIn**).

- 🏦 **Agora:** Specialist AI Engineer no **Asaas**, trabalhando com agentes de IA, automação de processos e plataforma de dados (Databricks, dbt, Airflow, Terraform).
- 🌱 **Estudando:** dbt (já no intermediário), Loop Engineering e avaliação de agentes.
- 🧪 **Open source:** [BoostPrompt](https://github.com/AirtonLira/boostprompt) e [LoopForge](https://github.com/AirtonLira/loopforge).
- 🎓 **Formação:** Análise e Desenvolvimento de Sistemas (FIA) · Especialização em Banco de Dados (UNIESP).
- 📍 João Pessoa, PB · trabalho remoto.
